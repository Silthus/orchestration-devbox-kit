# Source and licenses

This is a standalone snapshot of an optional Fleet export. Imported skill
licenses are in `provenance/licenses/`. Source revisions and export patches
are recorded in `provenance/skills.json`. Each imported work retains its
original license. User-owned workflow instructions and setup scripts are
published here by their owner.

The kit contains no account credentials, Fleet machine inventory, personal
Git identity configuration, or hub authorization keys. It does not require
access to the source Fleet repository.
